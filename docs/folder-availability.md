# Folder availability and encrypted search

PL051 and PL070 distinguish a complete document-tree listing from an unavailable one. A null child cursor, a directory cursor reporting loading or an error, and provider interruptions with a retained grant make the tree unavailable for that refresh. The traversal discards partial results, including previously listed siblings. A complete empty listing represents an empty folder. A missing persisted grant or a provider security denial takes the access-loss path.

Searchable and retained records have different scopes. The available listing drives results and model work. An unavailable tree keeps its encrypted OCR, scene, identity, confirmed-name, clothing and approved cloud-text records. Only records tied to that exact tree grant qualify. The app blocks source reads for a tree that its latest listing marked unavailable. Coordinate extraction works on the MediaStore path and is outside this folder change.

The **Manage folders** dialog labels unavailable folders and offers **Retry folders**. An app resume also refreshes sources. Reconnected photos reuse rows only when source and model revisions still match, with the existing pixel validation for photos that lack stable metadata. Removing the grant or completing a listing without a formerly indexed photo prunes its derived rows.

Android document providers signal incomplete and failed directory results through cursor extras. Providers that return an ordinary empty result for a disconnected tree are indistinguishable from empty folders to this client. Physical removable media and alternate device APIs need separate qualification. Live notifications now trigger the reconciliation described in source-observation.md. [Android DocumentsProvider API](https://developer.android.com/reference/android/provider/DocumentsProvider) · [DocumentsContract cursor extras](https://developer.android.com/reference/android/provider/DocumentsContract)

## Removable gallery storage

Gallery enumeration now compares the attached volume set before and after querying MediaStore. Photos on a volume that detaches during the query are excluded from the result. With full gallery permission, recently available volumes reported by StorageManager retain their encrypted derived records while detached. A null merged-gallery cursor also preserves records for the affected attached volumes. A complete empty result on a mounted volume follows normal deletion reconciliation.

Limited gallery permission and revoked gallery permission clear the detached-volume retention scope. Document-tree grants have their own scope. The same availability object flows through OCR, scene vectors, identity review, confirmed names, approved cloud text, garment evidence and location cache maintenance. Current accessible revisions still control reuse after reconnect. The Sources menu reports the count of unavailable gallery volumes and provides retry.

StorageManager exposes both currently and recently available volumes on API 30 and later. Android encourages preserving indexed metadata for recently available volumes because they can return. Records are retained while Android reports the volume in that recent set and full gallery access remains granted. [StorageManager recent volumes](https://developer.android.com/reference/android/os/storage/StorageManager#getRecentStorageVolumes()) · [MediaStore volumes](https://developer.android.com/reference/android/provider/MediaStore#getExternalVolumeNames(android.content.Context))
