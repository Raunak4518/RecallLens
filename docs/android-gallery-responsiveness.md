# Search responsiveness on a large phone gallery

The Motorola Edge 50 Pro reported an Android input-dispatch timeout on 18 November 2026 after a key event waited 10 seconds. The captured main thread was runnable in `ArrayList.contains` under `LibraryViewModel.withResults`, reached from the Compose text field callback. The gallery later reported 16,247 accessible photos. The incident summary is in `app/build/anr-phone-verification/incident.json`.

The installed hotfix updates the search field immediately, waits briefly for typing to settle, and prepares the results on a background dispatcher from captured text maps. Blank search skips result preparation. Text and filename lookup runs once where needed, and result membership uses a set or the already matched photos instead of scanning a list for each gallery row. Query publication preserves separate indexing state and checks that the search and photo scope are still current.

The hotfix passed 16 focused Android checks, 25 host checks, build, and lint. It was installed over the existing app with the same package and signing identity, preserving its local data and permissions. The app relaunched in 950 ms as reported by `adb am start -W`. The focused activity exposed an editable search field while coverage was 344 of 16,247 photos. This confirms the updated UI opened and supplied the live counter. It does not establish complete indexing or a sustained phone latency measurement. Phone manual testing remains the acceptance for the original interaction. Build and installation evidence is in `app/build/typing-anr-hotfix-acceptance` and `app/build/anr-phone-verification`.

A follow-up routes cache and source refreshes through the same background search preparation. This closes the path where a batch of newly available OCR could trigger a full search on the UI thread. Replacing a pending calculation on cache updates also prevents a result based on old cached text from overwriting newly available matches. Its separate acceptance run passed 20 Android checks, 25 host checks, build, and lint.

The single-prompt update uses the same indexed photo set for the processed count, gallery, and search scope. It passed 22 Android checks, 25 host checks, build, and lint. The tests verified that a filename match cannot surface an unprocessed photo. The verified APK installed over the existing app on the Motorola Edge 50 Pro and relaunched in 1,500 ms. The test and installation evidence is in `app/build/single-prompt-phone`.
